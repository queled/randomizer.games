# Contributing to Randomizer.Games

Merci de vouloir contribuer ! 🎉

## Comment démarrer ?

1. Fork le repo
2. Clone ton fork : `git clone https://github.com/YOUR_USERNAME/randomizer.games.git`
3. Crée une branche : `git checkout -b feature/ta-feature`
4. Fais tes changements
5. Commit : `git commit -m "feat: description"`
6. Push : `git push origin feature/ta-feature`
7. Ouvre une Pull Request

## Standards de code

- **JavaScript** : Eslint config (voir `.eslintrc.json` si présent)
- **Commits** : Format Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`)
- **Variables d'env** : Ne jamais commiter `.env` (toujours dans `.env.example`)
- **Documentation** : Commenter le code complexe

## Tests

```bash
npm run test
npm run lint
```

## Types de contribution

### 🐛 Bugs
- Ouvrir un issue avec reproduction steps
- Inclure version Node.js et OS

### ✨ Features
- Discuter d'abord via une issue
- Accepter une PR ne garantit pas la fusion
- Documenter la nouvelle fonctionnalité

### 📚 Documentation
- Typos, clarifications, exemples
- Plus facile que du code !
